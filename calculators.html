КЛИНИЧЕСКИЕ КАЛЬКУЛЯТОРЫ

Калькуляторы в кардиологии

Единый раздел для встроенных шкал риска и клинических расчётов CardioShort.

ОКС

GRACE 2.0 — оценка риска при ОКС; калькулятор уже реализован в разделе NSTEMI.

В дальнейшем: CRUSADE/ARC-HBR и другие шкалы только там, где они реально меняют клиническое решение.

ФП / ТП

CHA₂DS₂-VA — современная ESC 2024 оценка тромбоэмболического риска для принятия решения об антикоагуляции.

Также возможно добавить CHA₂DS₂-VASc для сопоставления с ACC/AHA/локальными рекомендациями и клиническими системами.

ТЭЛА

PESI / sPESI — прогноз раннего риска; для решения об амбулаторном лечении использовать вместе с клинической оценкой и критериями безопасности.

На странице ТЭЛА дополнительно используется новая классификация AHA/ACC 2026 A–E.

Сердечная недостаточность

рСКФ, клиренс креатинина и другие расчёты должны использовать валидированные формулы и учитывать контекст конкретного препарата/исследования.

План развития

Калькуляторы будут добавляться как интерактивные формы: ввод параметров → автоматический расчёт → краткая клиническая интерпретация → ссылка на раздел рекомендаций.

Источники

Только валидированные шкалы из ESC, ACC/AHA и РКО/SCARDIO либо оригинальных публикаций с последующей проверкой алгоритма.

Калькулятор не заменяет клиническое решение. Перед публикацией каждого интерактивного алгоритма формула и пороговые значения должны быть отдельно протестированы.

КЛИНИЧЕСКАЯ ТЕМА

Сердечная недостаточность

Практическая выжимка по диагностике и лечению СН. Основа: ESC 2021 + Focused Update 2023; классы рекомендаций приведены там, где они установлены руководством.

1. Диагностика

  • Подозревать СН при одышке, ортопноэ, снижении толерантности к нагрузке, утомляемости, отёках; искать признаки застоя и гипоперфузии.
  • ЭКГ, общий анализ крови, креатинин/eGFR, электролиты, печёночные показатели, глюкоза/HbA1c, липиды, ТТГ, ферритин и насыщение трансферрина.
  • BNP/NT-proBNP используются для исключения/подтверждения вероятности СН и отбора пациентов на ЭхоКГ.
  • Трансторакальная ЭхоКГ: ФВ ЛЖ, размеры камер, функция ПЖ, клапанная патология, диастолическая функция и косвенная оценка давления в лёгочной артерии.
  • При неясной этиологии — КМР, оценка ишемической болезни, генетическое/специальное обследование по клинической ситуации.

2. Классификация

  • HFrEF: ФВ ЛЖ ≤40%.
  • HFmrEF: ФВ ЛЖ 41–49%.
  • HFpEF: ФВ ЛЖ ≥50% при наличии симптомов/признаков СН и объективных данных структурной/функциональной патологии сердца и/или повышенных натрийуретических пептидов.
  • Функциональный класс NYHA I–IV — по выраженности симптомов и ограничению физической активности.
  • При острой СН дополнительно оценивать наличие застоя и гипоперфузии, гемодинамическую стабильность и провоцирующую причину.

3. Лечение

3A. Медикаментозное

HFrEF — базовая терапия:

  • Ингибитор АПФ для снижения риска госпитализации по СН и смерти, если ARNI не применяется — ESC Class I.
  • Сакубитрил/валсартан как замена ингибитора АПФ у подходящих симптомных пациентов для снижения госпитализаций и смерти — ESC Class I.
  • Доказанный β-блокатор — ESC Class I.
  • Антагонист минералокортикоидных рецепторов — ESC Class I.
  • Дапаглифлозин или эмпаглифлозин — ESC Class I, независимо от наличия сахарного диабета.
  • Петлевой диуретик при признаках задержки жидкости/застоя для уменьшения симптомов — ESC Class I.

HFmrEF/HFpEF:

  • Дапаглифлозин или эмпаглифлозин для снижения риска госпитализации по СН или сердечно-сосудистой смерти — ESC 2023 Class I, Level A.
  • Диуретики при застое; активное лечение АГ, ФП, ИБС, ожирения, диабета, ХБП и других причин/коморбидностей.

Острая СН: кислород при гипоксемии, внутривенные петлевые диуретики при застое; вазодилататоры, инотропы/вазопрессоры и механическая поддержка — только по гемодинамическому профилю и показаниям.

3B. Устройства / хирургическое и интервенционное лечение

  • ICD для первичной/вторичной профилактики внезапной сердечной смерти у отобранных пациентов после оптимальной медикаментозной терапии — показания определяются ФВ ЛЖ, этиологией, симптомами и ожидаемой продолжительностью жизни.
  • CRT при подходящей симптомной HFrEF, особенно при ФВ ЛЖ ≤35% и широком QRS/LBBB несмотря на оптимальную терапию.
  • Реваскуляризация и коррекция клапанной патологии — при соответствующих показаниях.
  • При терминальной СН — оценка в специализированном центре на LVAD/трансплантацию сердца.

4. Показания к выписке

ESC не сводит выписку после острой СН к одному универсальному балльному критерию. Практически перед выпиской необходимо добиться клинической стабильности и организовать раннее наблюдение.

  • Гемодинамическая стабильность без потребности во внутривенных вазоактивных препаратах.
  • Отсутствие нарастающей гипоксемии и признаков продолжающейся острой органной гипоперфузии.
  • Максимально возможное устранение клинически значимого застоя; переход с внутривенной на подходящую пероральную диуретическую схему.
  • Стабильные функция почек и электролиты либо сформирован чёткий план их контроля.
  • Начата/оптимизирована доказательная терапия настолько, насколько позволяет состояние пациента.
  • Установлена причина декомпенсации, даны рекомендации по весу, симптомам тревоги, препаратам и самоконтролю.
  • Организован ранний контроль после выписки и дальнейшая титрация терапии.
Основные источники: ESC Guidelines for acute and chronic heart failure (2021); ESC Focused Update (2023). Для профессионального использования; решения принимаются с учётом конкретной клинической ситуации.
